# Support

## Using the app

Open <https://somphol.github.io/platewise-3d/>. It works in current Chrome,
Safari, Firefox and Edge with WebGL enabled. The pantry, score and chart still
work if WebGL is unavailable; the 3D stage becomes a static panel.

## Bugs and feature requests

Use [GitHub Issues](https://github.com/somphol/platewise-3d/issues). Include the
browser, operating system, the URL, what you expected and what happened. A
screenshot helps for visual issues.

## Medical questions

**This project cannot answer them.** PlateWise is an educational visualization,
not a medical device. Talk to your clinician, diabetes educator or a registered
dietitian about your targets, medication and meal plan.

## Security

Do not file a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).
